# 视界 AIMaster 首页 · 开发交接包

这是一套供其他 AI 实现首页的设计文档、接口契约和真实素材，**不是已经开发好的网页**。主交互参考由用户选定为 Robotfolk；视觉继续采用已确认的明亮白蓝首页。

## 交给另一个 AI 的方式

1. 将“设计与开发交接包”和“三支视频原文件包”解压到同一目录，合并同名 `homepage-implementation-handoff-v1` 文件夹。
2. 把 `00_给实现AI的执行指令.md` 的全文发给它，并提供整个文件夹；如果工具只支持单篇文档，先提供 `首页完整设计文档.md`。
3. 要求先完成行业视频的一个完整交互，再扩展另外两种任务，最后提交电脑与手机的实际预览证据。

## 已锁定的交互

三任务顺序固定；视频与网页效果分离；原始／分析／对照共用同一视频；行业两种预设会改变算法链与结果；手机保留完整画幅并将操作移至下方；预约跳独立页面；无后端时使用明示的预设演示。

所有时间用视频呈现时间；切换预设回到有效片段起点，切换观看模式保留播放位置。播放窗口、目标与地面区域均由数据配置，不能让开发 AI 使用随机坐标画出似是而非的识别效果。

## 仍需在实现阶段补齐

- 原 Banner 同构图的独立干净背景图；目前只有完整布局参考。
- 三支实际视频的逐帧跟踪与区域标定，以及第三支白车参考小图。
- 网页传输用压缩副本、实际页面代码、浏览器与手机验收。
- 后端与真实预约服务属于后续阶段；本期不伪装成已接入。

本包已有素材和文档足以启动首页及三视频舞台开发。缺失标定数据被清楚列为实现任务，不是要求等待后端上线。
