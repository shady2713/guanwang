## 视觉与交互结论

| 项目 | 结果 |
| --- | --- |
| 首屏 | 保留理念、产品定位、城市影像与无人机，文字清楚。入口改为「开始巡查体验」，点击后收起首屏进入演示。 |
| 主体验 | 桌面同一画面左右展示巡查与节点，1440 × 900视口内可操作播放及查看证据。手机上下排列，避免缩小到不可读。 |
| 算法链 | 六节点可点击，说明与画面标记对应；关闭判断后跳过跟踪和进入条件。目标检索的输出详情不会再写成事件输出。 |
| 拖动与回放 | 区域离开车道时撤销进入提示，复位重新生成；鼠标、模拟触控与方向键均验收。时间轴回拨清除事件，离开区域后保留历史事件。 |
| 证据 | 固定背景中同一辆模拟车进入前后的位置发生变化；证据标签和时间对应，回放从事件前开始。 |
| 排版 | 不使用图中原有静态大面板作为整页背景。照片和功能标记独立，文本、按钮与节点均为实际HTML控件。 |
| 响应式 | 检查320、390、600、768、900、1024、1440px，无横向溢出；核心按钮至少44px高；手机任务顺序与桌面一致。 |
| 键盘与焦点 | 标签方向键、Home、End；区域方向键与Home；证据Escape和关闭焦点恢复；证据回放将焦点交给播放按钮。 |
| 动画 | 无人机缓慢悬浮、首屏收起、车辆连续移动、节点动态提示；减少动画偏好停用装饰动画与收起过渡。车辆回放由用户主动启动。 |
| 产品边界 | 页面明确标注预设素材与模拟结果；没有真实识别、无人机控制或在线检索，预约跳到独立静态页。 |

## 发现与修正

1. 共用样式的 `.hero > img` 曾令透明无人机铺满首屏，遮挡标题。已提高专用样式选择器优先级，限制尺寸并采用contain，桌面重新截图确认。
2. 区域操作柄曾处于车辆附近，遮住观察目标。已移到区域右下侧，并验证拖动、边界和复位。
3. 体验展开后首段过高，证据入口在900px视口下方。为较矮桌面收紧标题、节点间距及说明区，重新确认入口可见。
4. 手机标题曾孤立换出一个字，返回入口占用整行。已用适合小屏的字号并将返回入口放到眉题旁，重新查看截图。
5. 目标检索模式曾沿用行业模式的链标题与输出说明。现按模式同步更新标签和节点详情，浏览器验证自然语言与仅检测状态。
6. 证据回放会立即停用原证据按钮。已将焦点显式转移到播放控制，避免焦点留在已停用按钮上。
7. 图片尚未加载时证据入口保持停用，素材加载后重新计算可用状态，避免绘制未加载图片。

## 有意变化与限制

实际样片的首屏更高，无人机更明显，开始后首屏收起，适用于本轮沉浸体验要求。巡查画面使用固定滨水道路及一辆独立透明素材，不模拟真实航线或移动相机。证据从初始稿的常驻缩略图移至点击查看，给巡查与操作保留空间。完整场景、集成、API等页面不属于此次样片范围；导航仍连接现有页面。上述变化已在并排比较中确认，不声称逐像素一致。

实际通过10项Node模型测试、79项Chromium浏览器断言以及静态网页脚本语法检查。浏览器过程中无运行错误、资源失败或外部请求；全部请求为本地GET。手机触控检查采用Chromium模拟及CDP触控事件，拖动结束后留550ms再点复位，以避开Chromium对合成拖动后的点击抑制。没有用鼠标点击冒充触控检查。
