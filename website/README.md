# 视界 AIMaster 官网静态原型

新增首页交互样片、应用场景页、场景详情与独立预约演示页。首页样片基于选定的 v7 视觉与本轮交互要求；应用场景采用 v4 第一版。延续「不止于识别，更在于理解」，采用明亮城市影像、白色背景、深蓝文字和蓝色按钮。纯 HTML、CSS、JavaScript，无运行时依赖，无需购买模板或安装框架。

## 本地浏览

在本目录执行 `node serve.mjs` 或 `npm start`。

- 应用场景：<http://127.0.0.1:4173/scenarios/>
- 首页交互样片：<http://127.0.0.1:4173/experience/>
- 预约演示：<http://127.0.0.1:4173/demo/>
- 示例详情：<http://127.0.0.1:4173/scenarios/detail.html?id=216&industry=city>
- 原首页：<http://127.0.0.1:4173/>

预览仅监听本机。新页面使用 ES Modules，应通过 HTTP 服务打开，不能双击 HTML 文件代替本地服务。`dist` 为静态站点文件；旧 `aimaster-static.zip` 是之前的首页存档，不包含本次新增页面。

## 本版交互与内容

- 首页样片点击「开始巡查体验」收起首屏并播放模拟巡查；同页可以选择任务、调整判断、移动区域、查看节点、拖动时间轴与回看事件证据。初始顺序为行业场景、自然语言、以图搜图。
- 行业示例为同一辆车辆由区域外进入区域内。移动关注区域会重算进入时刻；关闭事件判断仅保留目标展示，回拨至进入前会清除当前事件，离开区域后保留已经发生的事件。
- 自然语言仅支持示例「查找白色车辆」；以图搜图使用固定参考图。两者只展示预设目标与位置，不会自动生成事件规则。所有运动位置、事件和证据由本地模型模拟，不运行真实 AI，也不控制无人机。
- 点击「查看事件证据」查看同车进入前后两帧；支持回放、Escape 关闭和焦点恢复。电脑左右布局，手机上下布局，移动区域支持鼠标、触控和方向键。
- 同页展示分类与内容，默认城市治理。16 个行业与 13 类能力按浏览方式切换，每次只显示一组分类。
- 接入完整 217 个规划主项、576 个行业关联；这些数字不是已训练模型数，也不能相加作为能力数量。
- 默认六个场景，加载更多追加同类内容。切换类别重置展示数量；直接链接及返回保留分类与加载状态。
- 电脑三列、平板两列、手机一列。手机分类完整铺出，触控按钮至少 44px 高；支持折叠导航、键盘标签切换、Escape 关闭和减少动画偏好。
- 详情保留该行业的用途、细分范围和使用条件。未逐项映射的行业会提示适配待确认；跨行业能力放在明确标注的折叠区。
- 详情解释算法链的配置思路，没有把规划目录描述为每个场景均已实现固定算法链。
- 预约入口进入独立页面，仅含公司名称与联系方式；有必填和格式检查，携带咨询场景。没有接收服务，填写不会发送，也不显示预约成功。禁用 JavaScript 时提交按钮停用。
- 原首页视觉保留，只把应用场景导航连接到新页，并将预约入口改为跳页。旧首页弹窗与测试文件作为历史记录保留。

## 内容与素材维护

`scripts/prepare-scenario-data.mjs` 从 `../outputs/application-scenarios-design-v2/website-scene-content.json` 生成公开数据投影，剔除内部绝对路径与竞品比较材料。上游内容未被改动，输入哈希保存在 `checks/catalog-source.json`。更新源目录后运行 `npm run prepare:scenarios`，然后执行检查。

所有场景支持状态仍为未确认；不得据此宣称全部支持或全部训练中。采集参数是未经现场验证的试拍建议，不是厂家验证范围、识别保证或安全距离。测量、变化分析等场景须遵循各自数据与设备条件。

城市及场景图片是生成的场景示意，不是客户案例或产品实测结果。首六项有独立图片，其余使用标注为「能力类别场景示意」的通用图。WebP 与手机 640px 版本位于 `dist/assets/scenarios`；原始 PNG、提示词和来源元数据保存在 `checks/asset-sources`。首页样片的空道路、透明车辆与无人机位于 `dist/assets/experience`，来源、提示词及空道路原图在 `checks/experience-asset-sources`。照片、车辆素材均独立制作，未将整张网页参考图作为页面背景。图标采用 [Tabler Icons](https://github.com/tabler/tabler-icons)，MIT 许可证随图标保留。网页无外部图片、字体或 CDN 请求。

- `checks/check-scenarios-browser.js`：Chromium 中 95 项检查通过，覆盖全部 16 / 13 分类、城市 72 项全部可达、加载与返回、手机导航、键盘操作、详情、表单、原首页连接、图片和网络。
- 320、390、600、768、900、973、1440px 场景布局正确；320、390、768、1440px 详情及预约无横向溢出。
- 另行完成 390px、2 倍像素密度的手机触控模拟；禁用 JavaScript 时验证 Enter 不产生表单请求，共 5 项通过。
- 浏览器检查无 JavaScript 运行错误、HTTP 资源失败或外部服务请求。仅使用虚构表单信息。
- 完成首页选定稿与实际截图的整页、重点区域并排比较，记录见 `design-qa.md`。应用场景页之前的验收保存在 `checks/scenarios-design-qa-2026-10-07.md`。

所有测试记录与截图在 `checks`，不属于网站发布内容。尚未在真实 iOS / Android 设备或 Safari 中验收。当前没有 AI 后端、真实预约接收、CMS、正式案例视频或公网部署；未提交、推送或发布。
